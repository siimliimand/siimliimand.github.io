## Approach

The user's request ("more modern", readability complaints) resolves into two concrete, measurable defects:

1. **Navigation contrast** — nav link text does not reach WCAG 2.1 AA contrast against the header background. Fixed by re-declaring the header/nav palette as custom properties and verifying every state (default, hover, focus-visible, active indicator) with the harness.
2. **Hero overlap** — the giant background "Siim Liimand" sits directly under the headline block. Fixed by pushing that layer behind the content (negative stacking order), dropping its opacity to ≤ 0.12, and marking it `aria-hidden` so it reads as a quiet watermark instead of competing text. The headline's own AA contrast is verified against its effective background.

Work is test-first: the harness task lands fixtures and subcommands (`contrast`, `hero`) with distinct exit codes (0 pass, 1 assertion failure, 2 usage/parse error), then both fix tasks consume it independently, and a short docs task records the final palette and measured ratios.
